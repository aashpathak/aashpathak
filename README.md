## 🚢 Main Project: OceanTrail (Pinned Repository)

**OceanTrail: A Web-Based Tool for Maritime Visualisation and Analytical Insights**

My MSc dissertation at Maynooth University, a full-stack maritime intelligence platform processing 282,000 AIS records for vessel emissions assessment, port dwell measurement, and traffic analysis of Irish coastal waters.

- 🔵 **AIS Data Pipeline**: 96.6% LOCODE resolution rate, ~30% status-region mismatch correction
- 🔵 **Port Dwell Algorithm**: Dual-layer spatial grid (100m precision + 5km meta-cells), vessel state classification across Dublin, Cork, Rosslare, and Waterford ports
- 🔵 **STEAM Emissions Module**: CO₂ at 3.206 t CO₂/tonne HFO from vessel class, speed, and operational state; supports EU ETS and IMO CII compliance
- 🔵 **Live deployment** on Render through Supabase/PostGISf DBS systen covering all major Irish ports and coastal shipping routes
